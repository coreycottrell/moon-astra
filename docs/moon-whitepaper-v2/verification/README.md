# Publication verification

`checks.json` records the actual local HTTP/Chromium run. All checks passed on September 5, 2026. The test environment used the repository's Playwright 1.62.1 and installed Chromium 147, with a software-rendering fallback available. This is functional publication evidence, not a game performance benchmark or a public deployment check.

- Eight model studies rendered into clean PNG posters. Six use the shipped Blender GLBs; two use proposed geometry in the report's viewer module.
- Motion advanced while enabled and remained held while paused. Keyboard orbit, trim selection and reduced-motion behavior passed.
- All 24 chapters, images, anchors and desktop layout checks passed. The 390px mobile cover, contents menu and construction widget fit without body overflow.
- The construction calculator observes the four-worker assembly ceiling, the prefabricated-stage change and distance-dependent delivery. The growth explorer follows its explicitly printed simplified formula.
- Capability ancestry, browser-local note persistence, Markdown/JSON exports, no-JavaScript reading and a deliberately missing-model fallback passed.
- Root and `/moon-astra-whitepaper/` hosting, the trailing-slash redirect, static response bytes and GLB signatures passed. Missing resources returned 404. Normal operation produced no browser exceptions, missing requests or external runtime requests.
- The PDF is a tagged, unencrypted **37-page A4** document. Its cover and a representative body/model page were visually inspected after correcting dark-mode print backgrounds. Extracted text was checked for empty/near-empty body pages; the shortest body page has 181 words. HTML desktop, mobile, calculator, and gallery screenshots were also inspected.

Screenshots are regenerated by `verify.mjs` and included in the transfer package. They are ignored in Git to keep the authoring checkout smaller. The final PDF lives in the ignored `site/` build directory and is included in the checked publication ZIP.
